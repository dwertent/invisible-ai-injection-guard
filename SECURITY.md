# Security Policy

## Supported versions

The latest release of the `v1` major version receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/dwertent/invisible-ai-injection-guard/security/advisories/new) rather than
opening a public issue. Include a description, reproduction steps and the impact you observed.

A bypass, meaning hidden content that this action does not detect, is in scope. Please include an example
description, with invisible characters written as code points (for example `U+200B`) so the report itself is
readable.

You can expect an acknowledgement within a few days.
